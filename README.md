HOW TO USE
──────────
1. Open HER.html in any modern browser (Chrome, Firefox, Safari, Edge).
2. Replace the placeholder files in the assets/ folder with your real media.
3. Keep the exact filenames listed below so everything loads automatically.

EDITING CAPTIONS & QUOTES
─────────────────────────
All photo captions, clip labels, audio titles, and secret-box
quotes are plain text inside HER.html — search for the line
you want to change and edit it directly.

NAVIGATION
